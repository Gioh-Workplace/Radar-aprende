# RadarAprende

Plataforma de avaliação diagnóstica destinada a auxiliar professores da rede pública na identificação das dificuldades de aprendizagem dos alunos.

## Objetivo

Permitir que professores criem avaliações, acompanhem o desempenho dos alunos por habilidade e recebam recomendações de intervenção pedagógica.

## Funcionalidades planejadas

- Autenticação de professores e alunos
- Gerenciamento de turmas
- Cadastro de habilidades
- Criação e publicação de avaliações
- Realização de avaliações pelos alunos
- Correção automática
- Dashboard de desempenho
- Recomendações pedagógicas

## Tecnologias

### Front-end

- React
- TypeScript
- Vite

### Back-end

- Node.js
- Express
- TypeScript
- Mongoose

### Banco de dados

- MongoDB Atlas
