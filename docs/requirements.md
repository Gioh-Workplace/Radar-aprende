# Requisitos do RadarAprende

## Fluxo principal

1. Professor acessa a plataforma.
2. Professor cria uma turma.
3. Professor adiciona alunos.
4. Professor cria e publica uma avaliação.
5. Aluno acessa a plataforma.
6. Aluno responde à avaliação.
7. O sistema corrige as respostas.
8. Professor visualiza os resultados por habilidade.
9. O sistema apresenta recomendações pedagógicas.
